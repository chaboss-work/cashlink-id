The story of CashLink ID

Nostr gives millions of people a portable identity, and they tip each other all day with Lightning "zaps".

Bitcoin Cash has fast, cheap, on-chain payments — but nothing tells you that bitcoincash:qr… really belongs to @alice. An address pasted into a profile proves nothing.

WizardConnect wallets can sign transactions but not messages. So we made the transaction itself the proof: the wallet signs a tiny commitment on chain, the Nostr key signs the matching event, and any app can check both.

Benefits of CashLink ID

  • Verified badge: both keys signed it; checked live from relays + the blockchain
  • No middleman: no accounts, no database, no custody — just Nostr relays and Fulcrum

  • Sign in with CashLink: challenge–response login for any BCH app
  • Open protocol: spec, reusable verifier library, NIP-78 / NIP-73 tags, DID view

BCH usage

⛓ Commitment transaction

Wallet spends from the linked address with OP_RETURN "CLID" 01 <npub> <sha256(statement)>. SIGHASH_ALL ⇒ only the owner could sign it. ~300 sat.

⚡ Pay by identity

Resolve npub / NIP-05 → verify → build the payment → approve in your wallet → broadcast. Re-verified right before signing.

🧮 BCH VM in the browser

Verifiers evaluate the address input with libauth's BCH VM and read confirmations from any Fulcrum server.

🔑 Zero-fee wallet proof

For logins the wallet signs a 0-fee transaction carrying the challenge: verified, discarded, impossible to relay.
